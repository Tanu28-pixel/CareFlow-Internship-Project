# CareFlow Power BI Dashboard

## Dashboard Overview

The CareFlow Power BI dashboard provides an interactive view of simulated patient journeys, clinical pathway performance, waiting times, bottlenecks, and pathway deviations.

## Dashboard Pages

### 1. Patient Flow Overview
Displays total patients, total transitions, average waiting time, activity frequency, patient delay risk distribution, and patient journey summaries.

### 2. Bottleneck & Delay Analysis
Highlights activity-level bottlenecks, average and maximum waiting times, transition frequency, and patient delays.

### 3. Pathway & Risk Analysis
Presents clinical pathway conformance, conforming and non-conforming journeys, repeated clinical activities, deviation patterns, and patient flow alerts.

## Key Project Findings

- Total simulated patients: 200
- Total events: 1,365
- Total transitions analysed: 1,165
- Conforming journeys: 144 (72%)
- Non-conforming journeys: 56 (28%)
- Average transition waiting time: 65.93 minutes

## Tools Used

Power BI was used to create interactive reports and visualisations. Python, BigQuery, dbt, SQL, and PM4Py supported data generation, processing, analysis, and process discovery.

**Note:** This project uses synthetic patient data for educational and process analysis purposes.
